# 智课系统更新说明



1. 知识库问答新增重排序精排：向量召回 15 条候选由重排模型按问题语义精排，相关性低于阈值 0.3 的片段判定「实际未参考」，解决「考核方式」一问参考来源混入 4 页无关课件的噪声问题。
2. 增加AI调用统计与追溯记录模块
3. 新增系统内置本地模型：向量化内置 BGE-M3、重排序内置 Qwen3-Reranker-0.6B，本机 CPU 推理、免 API Key，权重部署时自动下载（镜像预置 / 启动拷入 / 惰性下载 / `manage.py download_models` 四路保障）。
4. 课件 PPT 逐页入向量库：课件从「原文拼接兜底」升级为真实向量检索，知识库主要内容终于可被语义命中。
5. 新增重建向量能力（教师端 / 管理端 / 管理命令三入口）：换向量模型后按课程 / 资料 / 课件 / 全站安全重建，四条防线保证失败时旧向量不丢。
6. 向量化 / 语音合成服务商收窄为通义千问与本地模型服务，杜绝模拟模式 64 维假向量污染真实向量空间。
7. 大模型配置改为按能力（对话 / 向量 / 重排序 / 语音）独立配置，连接测试展示真实请求 / 响应 / 耗时。
8. 长资料向量化自动分批（DashScope 单批 10 条上限），超过 10 片段的资料不再静默落入假向量。
9. 讲稿双批并发 + 配音 3 并发：30 页课件生成从约 3 分钟提速至约 1 分钟。
10. 生成进度持久化：刷新 / 关闭页面后自动恢复续跑，多标签页防重复认领。
11. 新增单页讲稿 / 配音独立重生成；配音换自绘播放器，修复 Chrome 原生控件把缓冲区误显为已播进度的问题。
12. 本地模型服务适配：TTS 支持 OpenAI 兼容端点（二进制直落），超时 / 发音人搬进管理端表单，改配置免重启。
13. 配音模型从已下线的 qwen-tts 迁移至 qwen3-tts-flash，错误体透出真实失败原因。
14. 考试选项乱序回看归序：回看与批改统一按原题顺序展示，修复「正确答案 C、D、B」乱序与解析字母错位。
15. 考试监控 5 秒自动刷新 + 手动刷新，带「更新于」时间戳自证。
16. 新增考后统计页：成绩分布 / 逐题得分率 / 选项分布 / 排名（乱序答卷自动归位统计，填空按得分率展示）。
17. 修复 Element Plus 2.14.2 MessageBox 类名变迁导致「生成试卷」确认框被全屏编辑器盖死的幽灵 bug。
18. 作业多附件化：教师附件可追加 / 移除 / 在线滚动预览，学生提交支持多附件引用。
19. 填空题按空赋分：每空独立分值、部分对给部分分，客观题徽章新增「部分正确」第三态。
20. 课程资料在线预览（Office / PDF 逐页出图、滚动加载）+ 下载还原原始文件名。

38. AI 学情分析深化 + 章节学习 AI 总结：班级学情分析报告由同步生成升级为异步任务化——生成过程进度可见、刷新或关闭页面后自动恢复续跑，每次报告落库可追溯，教师端新增「历史报告」列表，可按时间回看历次报告全文并随时重新生成；学生端新增章节学习 AI 总结——学生每完成一个章节的视频学习，系统自动聚合该章的视频进度、题库练习、作业、考试与问答记录生成章节画像，由 AI 输出本章知识点掌握情况（扎实 / 薄弱）、薄弱点、学习亮点、提升建议与下一步行动，学生在学习页以抽屉形式查看，且总结内容遵循成绩可见性门控（作业批改返回、考试发布分值后，对应成绩证据才对学生展示），移动端完成章节学习时实时提示「AI 总结生成中」；教师端同步开放该能力——可在学生详情页按章节查看班上每生的总结全文（教师视角为全量口径，不受门控限制），作为学情分析的细粒度输入。此外修复了历史报告摘要的 Markdown 格式未渲染（标题符号直接露出）、学生卡片预警标签堆积遮挡考试成绩指标、多课程班级下学生详情页章节总结加载报错「章节不存在或不属于该课程」等问题，并配套补充了后端接口回归测试与端到端自动化用例。
39. 题库文档导入解析预览编辑：教师端题库新增「导入题目」入口——上传 pdf / doc / docx / txt / md 文档（.doc 走 LibreOffice 兜底，白名单 + 魔数复检 + 10MB 上限），服务端规则解析（题型分段、题号、选项行内粘连切分、题干尾部「答案：/解析：」剥离、填空空位识别、甲乙丙丁选项 key 归一、跨页续接，docx 表格按文档顺序整表抽取），解析结果落入草稿批次并进入预览编辑：逐题修正（题型 / 章节 / 选项 / 答案 / 解析 / 分值 / 难度，与手动录入共用同一表单组件）、解析告警醒目标注、勾选纳入或剔除、一键全部入库；批量入库经规范化（填空题按空均分、判断题归一并补 A/B 选项）→ 结构校验 → 逐条序列化校验 → 精确查重（同课程同题干跳过且草稿保留、可改写后重试）→ 逐条明细返回、部分失败不整批回滚，成功项即时移出草稿、全部保存后自动删除上传文件（入库即删，原文截断留存供排查）；草稿批次持久化，刷新 / 离开页面后可从顶部待处理横幅恢复，预览编辑防抖回传不丢失。
40. AI 多类型混合出题异步化：教师端题库「AI 生成」弹窗升级——一次配置多题型组（每题型开关 + 数量 + 分值 + 难度，组级难度缺省继承全局），新增教学目标入口，总题数超 30 实时拦截；生成由同步阻塞改为异步任务：按题型组分批 LLM 调用、后组 prompt 带入前组已出题干防重复、单组失败不拖垮整体、Mock 兜底、防重复提交约束与 5/min 限流，进度按组细粒度可见（「单选题 3/5 · 多选题 1/3 · 已生成 4 题」），排队中 / 失败 / 超时态均可一键重试；生成上下文由课程级 3000 字截断改为按章节收敛（章节 PPT 前 40 页 + 章节挂靠知识片段，预算 8000 字），AI 消耗计入「题目生成」场景统计（QA 看板与成本可见）；完成后自动创建草稿批次并打开预览编辑入库（与文档导入共用预览与入库链路），生成中离开页面再回来自动恢复进度（进行中任务 + 待处理批次双通道），任务完成但未保存的草稿不丢失。
41. 题库导入与 AI 生题体验修订：导入弹窗移除「目标课程」字段（导入本就在课程上下文内，改为「导入到课程：XX（自动关联当前课程）」提示行），题目文件上传区与章节课件上传全面统一——样式对齐（渐变拖拽区、图标白盒、标题加描述三段式）且流程对齐（选择文件即自动上传解析、移除「解析并预览」按钮、新增「正在上传题目文件…→正在解析题目结构…→完成 / 失败」阶段化进度面板）；题目预览编辑表单整体重构（标签列统一对齐、选项输入框占满行宽、设为正确答案按钮两态等宽、题干 / 解析 / 参考答案自适应行高、预览态与手动录入控件皮肤统一），并修复手动添加题目弹窗表单因属性名不匹配一直未渲染的静默缺陷；新增「入库并发布」能力——预览抽屉底部勾选「入库后立即发布」后题目入库即为已发布（文档导入与 AI 生题共用，学生端章节练习立即可见），省去入库后逐题点击发布的重复操作，入库入口同时合并为单一「入库勾选的 N 题」主按钮（配合工具栏全选即全部入库）；修复 AI 生题进度失真——原按题型组计数导致单组恒显「1/1」且整次调用期间无任何进展，改为组内按 3 题 / 块分多次调用、进度按题计数逐块落库，横幅实时显示「正在生成多选题（4/10）…」并带动进度条推进，小块输出同时降低长 JSON 被截断导致整组丢弃的风险。
42. 注册通道可控化 + 手机号停止采集：新增平台级注册开关——管理端「用户管理」工具栏右侧新增「开放注册」开关（切换落操作审计），系统缺省为关闭（新部署环境自助注册默认关停），关闭时注册接口返回「注册通道已暂时关闭，请联系管理员开通账号」、登录页注册入口替换为关闭提示；同时按个人信息最小必要原则停止采集手机号——注册 / 个人中心 / 首登弹窗 / 管理端新建编辑账号 / 批量导入说明等全部入口移除手机号字段，用户资料完整度与入班校验由「姓名 + 手机号」放宽为仅「姓名」，管理端用户表 / 教师详情 / 教师导出不再展示手机号，存量手机号数据已清空（数据库列保留供未来短信能力使用）；并修正移动端登录页「用户名 / 手机号」与管理端「也可用于登录」两处误导性文案（手机号登录实际从未实现）。
43. 生产测试反馈四项修复：①题库导入——修复解析文本倒灌进最后一个选项的问题（「答案：C」整行被标记切分消费后选项续行状态未复位，后续「类型 3：终点不可达…」等解析裸行被并入选项 D；现标记行后进入解析区、解析裸行一律入账解析字段，「答案与解析」合并标记只取行首答案令牌防整段解析污染选项字母提取），导入告警徽标改用悬浮提示逐条展示告警原因（原原生 title 不显示）；②实验排课——班级下拉曾显示教师名下全部课程班级（过滤条件恒真），现只显示本课程班级（后端本就有班级课程关联校验，前端补齐过滤）；③AI 问答——修复相邻引用 [3][4] 只有第一个可点击的问题（正则排除字符误含 ]，第二个引用前字符为 ] 被漏链），课程级问题（未选中具体章节时）自动注入课程大纲（全部章节标题 + 各章课件页标题，不占引用编号位、从检索预算中扣成本），「这门课程主要讲哪些内容」不再漏章；④课程目录——手动创建章目录不再要求「第 X 章」前缀（原文件识别用的章标题判定规则误套手动录入，「概述」等无前缀标题被整行丢弃；授课计划文件自动识别仍只认「第 X 章/讲/单元」，防止正文编号行误识别）。
44. 章节排序号真正生效 + 章节简介可见：目录接口曾硬编码按创建顺序排列、覆盖排序号字段（排序号保存后从不影响列表顺序），现恢复按排序号排列（同号按创建顺序兜底），章下小节本就一直按排序号排不受影响；章节简介此前仅作为目录搜索的匹配关键词、界面上无任何展示位置，现教师端目录树与学生端学习页的章节行均在标题下方展示简介（超长单行省略、悬停看全文）；手动新增章节时排序号默认取同级末尾 +1，不再默认 0 与既有章节同号并列。
45. 课程级 AI 问答检索加深（与大纲注入互补）：课程级问题的检索条数从 5 条放宽至 8 条、资料注入预算从 3000 放大至 4500（×1.5）——单纯加条数不解决漏章（向量相关性向概述章集中，多取的仍是同一章片段；且注入受 token 预算约束、预算不变加条数等于没加），故条数与预算同比例放宽保「每章有细节」，大纲注入保「每章都提到」；两项参数均可用环境变量覆盖（AI_QA_COURSE_TOP_K / AI_QA_COURSE_BUDGET_RATIO），章节内问答口径不变（top_k=5 / 预算 3000），避免单章问答引用噪声与延迟上升。
46. 题目题干配图（手动上传 + 文档导入自动提取）：题目新增题干配图能力（几何图 / 网络拓扑图 / 流程图 / 截图类题目）——教师端新建 / 编辑题目与导入草稿预览均可上传题图（选择即传，PNG/JPG/GIF/WebP/BMP ≤5MB，扩展名 + 大小 + 图片真伪三层校验，文件名 uuid 化防枚举，保存时服务端双重校验路径前缀防目录穿越，清空即移除）；文档导入自动提取内嵌图——docx 按文档流逐段提取、图片紧随其原文位置挂到对应题目（表格内插图同样支持，旧版 .doc 经 LibreOffice 转换后同路径），pdf 按图片在页面上的实际位置与文本交错定位（PyMuPDF），提取失败仅告警不阻断导入；学生端章节练习、考试作答、考后回顾、错题本、作业作答与结果页全部展示题图（点击放大、居中、支持缩放旋转），教师端批阅、试卷查看、考试 / 作业统计同步展示；作业与实验的题目快照同步冻结题图地址（发布后换图不影响已发布内容，与题目文本快照同语义）。
47. 题图交互与入库体验修订：题图上传区布局重做——固定尺寸缩略图（草稿预览紧凑态进一步缩小不撑高卡片）+ 纵向操作按钮列 + 独立格式提示行；放大预览弃用自绘弹窗（图片顶部对齐、无法缩放），改用内置预览器——图片居中显示，工具栏支持放大 / 缩小 / 旋转 / 复位；修复入库后题目列表不可见的两类场景——其一为筛选态遮挡（入库成功后虽刷新列表但保留旧筛选，新题被过滤，手动刷新页面恰好清空内存筛选才可见；现入库成功后自动重置全部筛选并回第 1 页），其二为部分入库漏通知（部分题因题库已存在被跳过、批次仍有剩余草稿时不触发刷新事件，直接退出预览父层不感知；现预览抽屉记录本次是否有题成功入库、关闭时补发刷新通知，全部完成的场景做了防重复处理）。
