## 4. 过程中发现并修复的缺陷

1. **`exam-submissions/start` 误拦「恢复在途答卷」**（真缺陷，写 L2 时自查发现）
   `start` 同时也是 ExamTaking 每次进页恢复答卷的入口。原实现在查考试之前无条件拦学籍——学生开考后毕业/休学，刷新或重进答题页会被 403 弹回列表，**已开考的答卷永远交不上去**，「交卷不拦」只剩直接调 submit 一条路，形同虚设。
   修复：先查该生此考试是否有 `in_progress` 答卷，有则放行；补 L1 单测 `test_resume_in_progress_allowed_but_new_exam_blocked` + L2 P4-3b 检查。

2. **Learning.vue 休学闸挂错了条件**（前端真缺陷，E2E 前自查发现）
   学习页课程来源是**班级接口**（按占用关系返回，不含学籍），休学生 `courseId` 仍有值，最初挂在 `v-if="!courseId"` 上的闸门永远不会触发，休学生照样能进章节树。
   修复：改为独立的 `v-else-if="eduStatus === 'suspended'"` 闸（课程空间深链同样拦）。

3. **L2 脚本夹具两处假阳性/预期错**（非产品缺陷）
   - `room_next` 与旧班同挂一门课 → 「转班后旧课消失」必然失败（L1 同款坑 L2 漏改）；改为新班挂「P4课程-进阶」。
   - P4-5 分母预期没算 P4-4 转进来的 D，实际 3 人；预期改为 3→2、33%→50%。

4. **E2E 点击 force 勾选落空**（非产品缺陷）
   Element Plus 的 class 透传到组件**根元素自身**：`<el-checkbox class="grad-force">` 渲染出的 label 同时带有 `el-checkbox` 与 `grad-force`，`.grad-force .el-checkbox` 后代选择器永不命中，force 没勾上，后续毕业全连锁失败。改点原生 `.el-checkbox__original`。

5. **考试不能创建时直接发布**（播种顺序，非产品缺陷）
   `perform_create` 挡「草稿直接发布」，组卷接口 `compose` 仅教师可调且锚点是课程负责人。E2E 播种改为：教师建课/建题/组卷/发布，管理员建班/建人/布置作业。
