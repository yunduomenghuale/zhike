**A2 JWT 登出吊销**
- 实现：`rest_framework_simplejwt.token_blacklist` 入库（refresh 拉黑）+ `User.tokens_invalid_before` 作废线（access 无黑名单机制的兜底，认证链 `RevocableJWTAuthentication` 校验 iat）。登出/停用账号均推进作废线；同秒内登出前签发的 token 必拒（int(iat) < 微秒级 cutoff 恒成立）。
- L1：`users/tests_p5.py` 4 项（登出后旧 access 401、旧 refresh 换新 401、作废线后新登录可用、停用账号 token 立即失效）。
- L2：P5-7 5 项全过。
- 已知取舍：登出后**同一秒内**重新登录的新 token 也会被拒（iat 整秒 < 微秒 cutoff），前端再登一次即恢复；真实交互远大于 1s，L2 用回拨作废线确定性验证了「作废线之后签发可用」。
