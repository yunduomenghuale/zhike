JDK 开发环境配置

三步完成：安装 → 配置环境变量 → 编译运行第一个程序

① 安装 JDK
② 配置 Path
③ Hello World

1安装 JDK 并确认版本

从官网下载与操作系统匹配的 JDK 安装包（Windows x64 / macOS ARM 等），按向导默认路径安装。
安装完成后打开命令行，执行版本查询命令确认安装成功。

C:\> java -version
java version "17.0.9" 2026-01-16 LTS
Java(TM) SE Runtime Environment (build 17.0.9+9-LTS)
提示：若提示「不是内部或外部命令」，说明环境变量尚未配置，继续第 2 步。

2配置 Path 与 JAVA_HOME

在「系统属性 → 环境变量」中新建 JAVA_HOME 指向 JDK 安装根目录，再把 %JAVA_HOME%\bin 追加到 Path 中。配置完成后重新打开命令行窗口（环境变量需新会话生效）。

JAVA_HOME = C:\Program Files\Java\jdk-17
Path += %JAVA_HOME%\bin
易错点：Path 中是 bin 目录；修改后必须重开命令行窗口，旧窗口不会刷新变量。

3编译并运行 Hello World

新建 HelloWorld.java，写入入口方法 main，用 javac 编译成字节码再由 java 运行。注意文件名必须与 public 类名完全一致（区分大小写）。

public class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello, Java!");
  }
}

C:\demo> javac HelloWorld.java
C:\demo> java HelloWorld
Hello, Java!
.java 经 javac 编译生成 .class 字节码，由 JVM 解释执行 —— 这正是 Java「一次编写，到处运行」的基础。
