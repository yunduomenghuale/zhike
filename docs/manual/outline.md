# 智课系统V2 用户手册 · 功能矩阵与截图清单

> 用途：手册撰写与截图采集的执行清单。覆盖 Web 端三角色（教师/学生/管理员），移动端不收录。
> 收录原则：教师/学生的「全局页 + 课程空间页」双入口以**课程空间**为主线撰写，全局入口在对应小节开头一句话说明；未挂路由的遗留页面（Placeholder.vue）不收录。

| 篇 | 文件 | 内容 |

| 第一篇 入门 | 01-入门篇.md | 系统简介、角色与账号、登录、工作台、个人中心 |

## 撰写模板（每个功能条目）

```
### N.M 功能名
**是什么**：一句话 + 使用场景。
**入口**：菜单路径（如：课程空间 → 题库）。
**前置条件**：权限/数据准备（无则省略）。
**操作步骤**：1. 2. 3.（配截图 ![](./assets/...)）
**完成后**：去哪里看效果。
**注意**：用户可感知的坑（如成绩发布规则、分批生成可离开页面等）。
```
