# 第二篇 教师使用指南

## 2.1 快速上手：一门课从创建到学生可学

教师的核心工作流如下，按顺序执行即可完成一门课的搭建：

1. **创建课程**：课程管理 → 新建课程，填写课程名称、学期等基本信息；
2. **班级准备**：班级由平台管理员创建并把学生加入班级（教师可给已有班级追加自己所授的课程，见 2.12）；
3. **生成章节目录**：进入课程空间 →「章节与课件」，可手动添加章节，也可用「授课计划识别目录」让 AI 从授课计划文档中提取目录；
4. **上传课件**：在章节节点上上传 PPT/PDF 课件，系统自动解析分页并入库（可检索）；
5. **生成讲解稿**：对课件逐页生成 AI 讲解稿（分批进行，可离开页面）；
6. **生成配音**：为每页讲解稿生成语音配音（分批进行）；
7. **发布章节**：章节发布后，学生在课程空间即可连播学习；
8. **配套建设**：上传知识库资料（供 AI 助教检索）、建设题库、布置作业、创建考试、查看学情。

后续小节逐一详解。

## 2.2 课程管理

**入口**：左侧菜单「课程管理」。

- 列表展示本人负责的课程卡片，点击课程进入**课程空间**；
- 点击「新建课程」填写课程名称、简介、学期（从统一学期字典选择，如「2026 秋」）；
- 课程卡片右下角的图标按钮提供「复用课程」等操作。

![课程管理](assets/teacher/T38-course-cards.png)

![新建课程](assets/teacher/T02-course-create.png)

### 复用课程（把已有课程快速复制成新课）

1. 在课程卡片上点击「复用课程」图标；
2. 弹窗先展示资产盘点（章节数、课件数、题库题目数等），据此判断复用范围；
3. 填写新课程名称、目标学期，选择是否连同题库一起复制；
4. 确认后异步执行并显示阶段进度，完成后可直接跳转到新课程。

![复用课程](assets/teacher/T39-course-reuse.png)

> 仅课程创建者可复用；同一课程已有进行中的复用任务时，再次点击会直接接上该任务的进度。复制在事务内完成，失败不留半成品。

> 侧边栏的「知识库 / 题库 / 作业 / 考试 / 学习统计」全局入口与课程空间内对应页签功能相同，区别在于全局入口需先选择课程；日常教学建议直接进入课程空间操作。

## 2.3 章节与课件

**入口**：课程空间 →「章节与课件」（默认页）。

页面左侧是章节树，右侧是选中章节的课件与生成状态。章节节点悬停显示操作图标：上传课件、生成配音、讲解稿、完整讲解预览等。

![章节与课件](assets/teacher/T03-chapters.png)

### 2.3.1 用授课计划识别目录

1. 点击页面顶部「授课计划识别目录」；
2. 上传授课计划文档（Word/PDF 等），系统自动识别章节结构；
3. 确认识别结果后生成目录；也可以随时用「手动添加」增补章节、拖动调整顺序。

![授课计划识别目录](assets/teacher/T04-plan-recognize.png)

### 2.3.2 上传课件

1. 在章节节点上点击课件（上传）图标；
2. 选择 PPT/PDF 文件上传，面板显示解析进度；
3. 解析完成后，课件按页展示缩略图与文字内容，自动进入课程知识库可检索范围。

![课件面板](assets/teacher/T05-ppt-panel.png)

> 同一章节重复上传会替换为新版本；解析失败的页面可重试。

> 章节的「排序号」决定列表中章的先后（同号按创建顺序），手动新增时默认取同级末尾 +1；「章节简介」会显示在教师端目录树与学生端学习页的章节标题下方（超长省略，悬停看全文）。

### 2.3.3 生成讲解稿与配音

1. 课件解析完成后，点击章节节点上的「讲稿」图标发起讲解稿生成；
2. 讲解稿按页分批生成（每小批数页），配音按页逐页合成，均在后台执行；
3. 顶部出现任务进度横幅，可离开页面处理其他工作，回来自动刷新；
4. 生成完成后，点击「讲稿」打开「讲解稿与配音」面板：逐页查看/校对讲稿文本、试听配音，可对单页「重新生成本页」讲稿或「重新配音」。

![讲解稿与配音面板](assets/teacher/T06-scripts.png)

5. 点击「完整讲解」进入整章连播预览（与学生端学习页一致），整体检验一遍效果。

![完整讲解预览](assets/teacher/T08-full-lecture.png)

> 讲解稿与配音的生成依赖管理员配置的 AI 能力；若生成失败，重试对应章节即可，已完成的页不会重复生成。

### 2.3.4 发布章节

讲稿与配音就绪后，将章节设为「发布」状态。只有已发布章节学生才可见、可学习；未发布章节对学生隐藏。

## 2.4 知识库

**是什么**：课程专属的资料库，上传的教辅资料经切分、向量化后成为 AI 助教回答的检索来源。

**入口**：课程空间 →「知识库」。

**操作**：

1. 点击右上角「上传教辅资料」，选择文件（支持 PDF/Word/PPT/TXT/Markdown 等）；
2. 上传后系统自动解析入库，列表中显示解析状态；
3. 资料可关联到具体章节（章节语义问题优先在该章节资料中检索）；
4. 资料失效可删除；**「重建向量」仅在你需要更换向量模型等运维场景使用**，日常使用无需点击。

![知识库](assets/teacher/T09-knowledge.png)

## 2.5 AI 问答

**入口**：课程空间 →「AI 问答」。

教师可在课程语料范围内试提问，验证知识库资料覆盖效果：回答附参考来源（讲稿/资料页级引用），资料不足时系统如实提示。教师提问语料与学生一致，常用于备课自检与答疑预演。页面右上角支持「新建会话」与「历史记录」回看。

![AI 问答](assets/teacher/T11-course-qa.png)

## 2.6 题库

**入口**：课程空间 →「题库」。支持单选、多选、判断、填空、简答五种题型。

**题目用途分类**：每道题带「用途」标签——**章节练习 / 作业 / 考试**（可多选，默认勾选「章节练习 + 作业」，避免新建的题目直接进了考试卷）。作业与考试的选题池按用途过滤：作业只抽带「作业」标签的题、考试只抽带「考试」标签的题，学生端章节练习只取「章节练习」类题目（防止作业/考试题提前泄露）。题库列表带用途标签列，可按用途筛选。

![题库列表](assets/teacher/T40-question-list.png)

### 2.6.1 手动录入

1. 点击「新建题目」；
2. 选择题型，填写题干、选项（客观题）、答案、解析、分值、难度、所属章节与**用途**；
3. 几何图、拓扑图、程序截图类题目可上传**题干配图**（PNG/JPG 等，≤5MB，选择即上传）；
4. 保存后题目进入题库；状态为「已发布」的题目才能被作业/考试选用。

![新建题目](assets/teacher/T41-question-create.png)

> 填空题按空设置答案与分值；多选题可设置漏选得分规则（以页面选项为准）。学生在练习、考试、错题本中看到的题图可点击放大（支持缩放、旋转、复位）。

### 2.6.2 文档导入

1. 点击「导入题目」，上传题目文档（PDF/Word/TXT/Markdown）；
2. 系统自动解析题目结构并打开预览抽屉：逐题核对、可直接修改；文档中内嵌的插图会自动挂到对应题目下（提取失败仅提示，不影响导入）；
3. 勾选题目后点击「入库勾选的 N 题」；如需立即用于作业/考试，勾选「入库后立即发布」；
4. 与题库中已有题目**题干完全重复**的题目会被跳过（保留在批次中，可修改后重试）。

![导入题目](assets/teacher/T14-question-import.png)

### 2.6.3 AI 生题

1. 点击「AI 生成」，选择题型、数量、难度与出题范围（章节/知识点）；
2. 任务在后台分批生成，顶部横幅显示进度，可离开页面；
3. 生成完成后自动打开草稿预览：逐题审阅、修改，确认后入库；
4. 未处理完的批次可从题库页「草稿批次」入口随时打开继续。

![AI 生题](assets/teacher/T15-question-aigen.png)

![草稿批次入口](assets/teacher/T16a-draft-batches.png)

![草稿批次预览与入库](assets/teacher/T16-draft-preview.png)

> 同一课程同时只允许一个进行中的生题任务；草稿批次未入库前可随时返回继续处理，或整批放弃。

## 2.7 作业

**入口**：课程空间 →「作业」。

### 2.7.1 创建作业

1. 点击「发布作业」；
2. 填写标题、说明、截止时间，选择目标班级；
3. 两种模式：**题库选题**（从本课程题库中带「作业」用途的已发布题目里选，客观题自动批改）或**附件作业**（学生上传文件，可附多份参考附件）；
4. 保存草稿或立即发布；发布后学生在课程空间「我的作业」中可见。

![作业列表](assets/teacher/T17-homework.png)

![创建作业](assets/teacher/T18-homework-create.png)

### 2.7.2 批改作业

1. 在作业列表点击对应作业的「批改」进入提交批改面板（显示已提交/待批改/平均分与提交名单）；
2. 客观题由系统自动批改；主观题逐人评分并填写评语；
3. 批改完成点击「提交批改」**发布**后，学生才能看到分数与评语。

![作业批改](assets/teacher/T19-homework-grading.png)

### 2.7.3 作业统计

作业列表 →「统计」：查看提交率、得分分布、每题正确率，定位普遍薄弱题目。

![作业统计](assets/teacher/T20-homework-stats.png)

## 2.8 考试

**入口**：课程空间 →「考试」。

### 2.8.1 创建考试与组卷

1. 点击「新建考试」，填写名称、考试起止时间、时长、目标班级；
2. 按需开启：题目乱序、选项乱序、防切屏监测、考后展示解析、允许重考；
3. 保存草稿后进入「组卷」：支持**手动选题**（勾选带「考试」用途的题目与分值）或**随机组卷**（按题型/难度/章节规则抽题，可每个学生一套卷）；在考试页直接编写的题目会自动带上「考试」标签；
4. 组卷完成后「发布」，学生在考试时间内即可进入作答。

![考试列表](assets/teacher/T21-exams.png)

![新建考试](assets/teacher/T22-exam-create.png)

### 2.8.2 监考与批改

- 考试中可通过「监控 / 批改」查看进行中状态与异常日志；
- 客观题交卷即自动判分；含主观题时需教师评分；
- 全部批改完成后，点击「统一出分（发布全部成绩）」，学生才能查看成绩与解析。

### 2.8.3 考试统计

考试 →「统计」：参考率、得分分布、每题正确率与清单，用于讲评与补测决策。

![考试统计](assets/teacher/T23-exam-stats.png)

> 注意：成绩发布前学生端仅显示「待出分」；发布后不可撤回，请确认批改无误再发布。

## 2.9 教学资源

**入口**：课程空间 →「教学资源」。

教学资源**直接归属课程、不再挂章节**，学生进入课程即可看到全部已发布资源。资源分三类：

| 类型 | 内容 | 来源 |
|---|---|---|
| **思维导图** | 知识结构图，适合整章/整课回顾 | 平台预置，或教师上传自制单文件 HTML |
| **交互演示** | 可操作的演示页（协议推演、配置步骤等） | 平台预置，或教师上传自制单文件 HTML |
| **文档** | PDF / Word 讲义与资料（单文件 ≤100MB） | 教师上传 |

**资源库页面**：顶部按「全部 / 思维导图 / 交互演示 / 文档」切换（带数量），支持搜索；每行可切换发布开关，行内提供「预览 / 复制链接 / 删除」。

![资源库](assets/teacher/T35-resource-library.png)

**添加资源**：

1. 点击「添加资源」打开弹窗；
2. 先选「资源类型」（默认「文档」）：文档类直接上传 PDF/DOC/DOCX（≤100MB）；导图/演示类再选来源——引用平台预置页，或上传自制的单文件 HTML；
3. 填写资源标题后「上传并添加」；
4. 保存后可在列表中预览，确认无误再打开发布开关。

![添加资源](assets/teacher/T36-resource-add.png)

![资源预览（自定义导图）](assets/teacher/T37-resource-preview.png)

> 资源的访问地址是**带时效的签名链接（2 小时）**，下架后立即失效；复制出去的链接会过期，长期分享请让学生从课程内进入。自制 HTML 资源在受控环境中运行（限制对外发起请求），不会外发学生信息。

## 2.10 虚拟实验

**入口**：课程空间 →「虚拟实验」。

创建/安排实验任务、查看学生提交与成绩；实验成绩**只看步骤评分**（原实验附带的题目作答与主观题批改已下线，教师批改界面不再出现实验题目项）。学生端在课程空间「虚拟实验」中进入。

![虚拟实验](assets/teacher/T27-labs.png)

## 2.11 学习统计

**入口**：课程空间 →「学习统计」。

- **班级学情列表**：按班级查看每名学生的最近学习时间、章节练习正确率、作业/考试提交与均分、实验完成情况，支持搜索与筛选；
- **章节 AI 总结**：学生详情页按章节查看该生的章节学习总结（含薄弱点证据，见下方「学生详情」）；
- **AI 学情报告**：对班级整体学情生成分析报告，支持历史报告回看；
- **学生详情**：点击学生进入个体页，查看其学习轨迹、作业考试明细与章节总结。

![学习统计](assets/teacher/T28-analytics.png)

**AI 学情报告**：点击「生成分析报告」发起（异步任务，完成后自动呈现）；点击「历史报告」可回看历次报告全文。

![AI 学情报告历史](assets/teacher/T30-ai-report.png)

**学生详情与章节总结**：点击学生进入个体页——顶部为预警标签与指标卡（学习进度、练习正确率、作业/考试提交与均分、实验情况），下方为明细数据；「AI 章节总结」区可按章节查看该生的学习总结（本章概览、知识点掌握、薄弱点、学习亮点等）。

![学生详情](assets/teacher/T31-student-detail.png)

![AI 章节总结（教师视角）](assets/teacher/T29-chapter-summary.png)

> AI 学情报告为异步任务：提交后顶部显示进度，完成后自动呈现；同一班级 10 分钟内不可重复生成。

### 导出班级学习数据（Excel）

1. 在学习统计页点击「导出 Excel」；
2. 选择课程与时间范围（本周 / 本月 / 本学期 / 自定义，选择结果本地记忆）；
3. 勾选需要的工作表：**成绩总览**（必含）、作业明细、考试明细、实验明细、练习与错题、问答与视频、章节矩阵；
4. 弹窗提示本次涉及的学生规模与时间范围，确认后生成单个多 Sheet 工作簿下载。

![导出班级学习数据](assets/teacher/T42-analytics-export.png)

> 成绩类数据统一折算为百分制（得分 ÷ 满分 × 100 后取平均）便于横向比较；导出为教师视角，不受学生端「成绩发布」门控限制。导出接口每分钟最多 10 次，频繁点击会提示稍后重试。

## 2.12 我的班级

**入口**：左侧菜单「班级管理」。

教师端为**只读视图**：可查看自己所授班级的信息与学生名单，但建班、删班、加人 / 移出 / 转班、学籍变更等操作均由平台管理员执行（见第四篇 4.3）。教师在班级上的可写操作只有一项——**给班级追加自己所授的课程**（追加语义，不会覆盖同班其他教师挂的课）。

1. 班级卡片上「学生」进入学生名单页，「课程」查看/追加该班已关联的课程；
2. 学生名单为独立页面：支持按姓名 / 学号搜索、按学籍与学习状态筛选、按最近登录等字段排序，每行带头像与最近登录时间；
3. 点击学生区域进入该生的学情详情（预警、指标卡、AI 章节总结）。

![班级列表](assets/teacher/T43-classes-readonly.png)

![班级学生名单](assets/teacher/T44-class-roster.png)

> 学生账号与入班由管理员维护；学生资料中**姓名**需完整，否则无法被加入班级。

## 2.13 问答质量看板

**入口**：左侧菜单「问答质量」。

监控本课程 AI 问答的运行质量：

- **指标卡**：提问量、检索为空率、改写触发率、好评率、评价覆盖率、兜底触发率等（悬停问号图标查看口径说明）；
- **问题下钻**：查看空答（未检索到资料）与被学生踩评的具体问题，据此补充知识库资料或优化章节归属；
- **课程级告警**：指标越过阈值时给出提示与处理建议。
