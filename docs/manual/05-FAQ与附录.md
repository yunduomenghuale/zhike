# 第五篇 常见问题（FAQ）与附录

## 5.1 账号与登录

**Q：登录提示用户名或密码错误？**
A：核对用户名（学号/工号）与密码大小写；新账号初始密码为 `Zk` + 用户名后 6 位。连续输错会临时锁定，请稍后再试或联系管理员重置。

**Q：登录页没有注册入口？**
A：系统默认关闭开放注册。需要账号请联系平台管理员创建；管理员可在「用户管理」工具栏打开「开放注册」开关。

**Q：忘记密码怎么办？**
A：联系管理员在「用户管理」中重置密码，重置后按初始密码规则登录并尽快修改。

## 5.2 学生常见问题

**Q：进入课程后看不到某些章节？**
A：只有教师已发布的章节对学生可见。请确认教师是否已发布该章节。

**Q：交卷后为什么看不到考试成绩？**
A：考试成绩由教师统一发布（「统一出分」）。发布前显示「待出分」是正常状态，请等待教师完成批改与发布。

**Q：作业提交后看不到分数和评语？**
A：作业需教师批改发布后才展示（界面显示「已发布 X 分」）。主观题需要教师逐人评分，请耐心等待。

**Q：截止后还能补交作业/进考试吗？**
A：不能。作业截止时间后无法提交；考试超过结束时间自动交卷或不可进入。请提前安排时间。

**Q：AI 助教回答「资料不足」？**
A：说明该问题超出本课程知识库资料覆盖范围。可以换更贴近课程的问法，或向教师反馈补充资料。

**Q：问答页没有图片上传入口？**
A：图片提问仅在管理员配置的对话模型支持图片理解时显示。当前未显示说明模型不支持，直接文字提问即可。

**Q：学习进度会丢失吗？**
A：不会。课件学习翻页即自动保存进度，下次从上次位置继续。

## 5.3 教师常见问题

**Q：课件上传后解析一直进行中/失败？**
A：解析在后台进行，大文件需要几分钟。若长时间未完成或失败，在课件面板重试；仍失败请检查文件是否损坏（可先在本地打开验证），或联系管理员确认 AI/解析服务状态。

**Q：讲稿/配音生成中断了怎么办？**
A：重新对章节发起生成即可。已完成的页不会重复生成，中断页会自动续做；生成期间可离开页面，顶部横幅会显示进度。

**Q：AI 生题/文档导入的题目去哪了？**
A：先入**草稿批次**，在预览抽屉中逐题审阅、修改后「入库」才进入题库。与题库已有题干完全重复的题目会被跳过并保留在批次中，可修改后重试。

**Q：为什么选不到某道题组卷/布置作业？**
A：作业与考试只能选用「已发布」状态的题目。草稿状态的题目请先在题库中发布（或入库时勾选「入库后立即发布」）。

**Q：修改已发布考试用的题目，会影响进行中的考试吗？**
A：会。考试试卷引用题目的实时内容，未交卷/批改中的考试可能受影响；请在考试结束后再修改题目。作业与实验使用题目快照，不受影响。

**Q：同一课程能同时跑多个 AI 生题任务吗？**
A：不能。同一课程同时只允许一个进行中的生题任务；可等其完成或放弃后再发起。不同课程互不影响。

## 5.4 管理员常见问题

**Q：配置了大模型但没生效？**
A：按优先级排查：管理端配置 > 环境变量 > 模拟模式。保存后在「当前生效配置」表格确认「来源」与「实际运行时」；保存后建议用「测试连接」验证。

**Q：更换向量模型后检索效果没变？**
A：向量模型更换后需在知识库执行「重建向量」，存量资料重新向量化后才按新模型检索。

**Q：操作审计里能看到 API Key 内容吗？**
A：不能。密钥加密保存，审计只记录「已配置/未配置」状态，不落密钥明文。

## 5.5 术语表

| 术语 | 说明 |
|---|---|
| 课程空间 | 进入某门课程后的工作区，含章节、知识库、题库、作业、考试、学情等页签 |
| 讲解稿 | AI 为每页课件生成的口播讲解文字 |
| 配音 | 由讲解稿合成的每页语音（TTS） |
| 知识库 / RAG | 课程资料经切分向量化后供 AI 问答检索的语料库；回答附参考来源 |
| 草稿批次 | 文档导入 / AI 生题的暂存区，审阅入库后才进入题库 |
| 批改发布 | 教师完成作业批改并提交，学生端显示「已发布 X 分」后可见成绩 |
| 统一出分 | 教师发布考试全部成绩的动作，发布后学生可见成绩与解析 |
| 章节总结 | 基于学生学习数据生成的章节级掌握情况汇总 |
| 空答率 | AI 问答中未检索到资料而未能回答的提问占比 |
| 模拟模式（Mock） | 未配置真实 AI 服务商时的演示模式，不产生真实 AI 效果 |
