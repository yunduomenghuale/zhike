## 三、非功能需求差距

- **异步任务缺失（10.2）**：PPT 解析、AI 生成、知识库入库全部请求内同步执行，大任务阻塞 3~5 分钟，无"生成中/成功/失败"任务状态展示。
- **向量库（7.2）**：embedding 以 JSON 存表，全表暴力余弦 top_k=5；embed 失败静默回退 Mock 哈希向量，检索质量悄悄劣化。
- **权限细节（10.3）**："学生只能访问本班资源"依赖各 ViewSet 自行过滤，需抽查越权旁路。
- **测试缺失**：无任何自动化测试。
- **数据库**：默认 SQLite，生产需确认 MySQL/PostgreSQL 配置路径。
