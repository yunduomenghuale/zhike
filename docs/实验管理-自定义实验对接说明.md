## 一、这套机制是什么

教师创建自定义实验只需两步：**填基本信息（标题、课程、总分等）**、**上传一个 HTML 文件**。系统随后给出成绩上报地址、按该实验参数生成的接入说明、以及在线调试。

学生做实验时：

1. 平台下发**父页面**（HMAC 门控），父页面用 `sandbox` iframe 加载你的 HTML，并在 iframe 内注入 `lab-bridge-shim.js`；
2. 页面调 `LabBridge.validate()`，经 `postMessage` 从父页面拿到实验总分；**一次性票据只存在于平台父页面，iframe 内完全没有**；
3. 学生在页面里操作，页面按自己的规则逐步判分，得出一个**总分**；
4. 页面调 `LabBridge.reportGrade({ total_score, elapsed_seconds })` → shim 经 `postMessage` 把分数交给父页面 → **父页面附加票据并代发 POST** → 平台校验 → 服务端补 `submitted_at` → 入库 → **实验完成，学生立刻看到分数**。

**平台不关心你有几步、每步怎么判、每步多少分。** 步骤名称、判分规则、分项明细全部属于 HTML 自己；平台只接收两个值，只存一个总分。

## 二、教师端在创建实验后会拿到什么

| 项 | 内容 |
| --- | --- |
| 成绩上报地址 | `POST /api/lab-gate/grade/`（平台同源路径，固定，全局一个；**由平台父页面代发，你的页面不直接请求**） |
| 接入说明 | 按该实验的名称与总分**动态生成的 Markdown**，由 `GET /api/labs/{id}/integration-spec/` 渲染；含请求/响应 schema、字段约束、错误码、最小 HTML 片段、以及可整段复制给 AI 的指令。点「复制给 AI」即可 |
| 在线调试 | `POST /api/labs/{id}/grade-debug/`，填一条模拟报文跑同一套校验，**dry-run 不入库** |
| 补充说明 | 可编辑的 Markdown（`report_note`），会追加在接入说明末尾，供 AI 参考 |

**接入说明不是新模块、不是新表单、不新增数据表**——只是把实验已有参数渲染成一段文字。你觉得「规格卡」这词绕，叫它「接入说明」即可。

**没有固定密钥、没有 API Key、没有步骤清单要填，页面也不需要读票据**。身份凭据是每次学生进入实验时动态签发的 `LabAttemptToken`（`X-Lab-Token`），2 小时有效、提交成功即作废；它**只在平台父页面** `lab-bridge-parent.js` 的 IIFE 闭包里，由父页面在代发上报请求时加到请求头。你的 HTML 运行在 `sandbox` iframe 内，**编写时和运行时都拿不到票据**。

> **v3.2 说明**：票据仍会出现在**平台父页面**里，学生在自己这次会话中可从「查看源码 / 网络面板」看到**自己本次**的票据（用户已接受）。但这与「你的 HTML 拿不到票据」是两回事——iframe 是独立的 opaque origin，读不到父页面的任何变量、存储或请求头。这不改变第九节「挡不住伪造满分」的结论。

## 三、请求约定

> **v3.2**：下面这段是**平台父页面替你发出的 HTTP 请求**。你的 HTML 在沙箱 iframe 内，**不要自己发这个请求**（跨域会被拦，且 iframe 内没有票据）；只需调 `LabBridge.reportGrade(...)`。

```http
POST /api/lab-gate/grade/ HTTP/1.1
Host: <平台域名>
Content-Type: application/json
X-Lab-Token: <由平台父页面自动附带，iframe 内页面不接触>
```

页面实际只需调用 `LabBridge.reportGrade(...)`，请求体**只有两个字段**：

```json
{ "total_score": 86.5, "elapsed_seconds": 742 }
```

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `total_score` | number | 是 | 0 ~ 实验总分，最多 1 位小数 |
| `elapsed_seconds` | number | 是 | ≥ 0，页面自报的用时秒数；**平台不采信**，仅留痕 |

**就这两个字段。** 另外：

- **`submitted_at`（提交时间）由平台服务端生成，页面不传**；传了也会被忽略。原因是浏览器时间学生可改，采信它等于没有截止时间。
- **正式入库的用时由平台按 `submitted_at - started_at` 服务端计算**（v3.1 / S1）。页面传的 `elapsed_seconds` 仍请如实填，它会被记进原始报文供教师对账，但**不会覆盖平台算出的用时**、也不参与任何判定；不要在页面里为了「好看」改写这个值。
- 不需要上报步骤明细、步骤 key、每步得分；平台不校验也不存储这些。
- 不要自己拼 `X-Lab-Token`，也不要读 `location.search` 里的票据；**iframe URL 里本就没有票据**，上报票据只由平台父页面处理。
- 整个请求体序列化后 ≤ 64KB（只有两个数字，正常永远达不到）。

> 页面判分时请把总分算准：它必须在 `0 ~ 实验总分` 之间，最多 1 位小数。超出范围的提交会被拒绝，但**不会作废票据**，学生可以重试。

## 四、响应约定

成功：

```json
{
  "code": 0,
  "message": "成绩已提交",
  "data": {
    "submission_id": 1234,
    "total_score": 86.5,
    "status": "submitted",
    "submitted_at": "2026-11-05T10:30:00+08:00",
    "graded_at": "2026-11-05T10:30:00+08:00"
  }
}
```

`status: "submitted"` 即代表**实验已完成**，立即进入学情统计、报告生成与成绩列表。

失败（统一 `{code, message, data}`，`code != 0`）：

| 场景 | HTTP | message 示例 |
| --- | --- | --- |
| 票据缺失/无效/过期/已消费 | 401 / 400 | 实验票据无效 / 已使用 / 已过期 |
| 学籍被暂停或不在班 | 403 | 中文拦截原因 |
| 已提交过（status 非 in_progress） | 400 | 本次实验已提交 |
| 总分越界或不是 1 位小数 | 400 | 成绩超出实验总分范围 |
| 用时为负 / 报文过大 | 400 | 上报内容非法 |
| 触发限流 | 429 | 提交过于频繁，请稍后重试 |

**重试语义**：任一失败都不写成绩、不作废票据，学生可直接重试。上报成功才消费票据，之后不可再提交（自定义实验默认不允许重做）。

## 五、页面侧桥接 API（`window.LabBridge`）

平台在 **iframe 内**自动注入 `lab-bridge-shim.js`，在**平台父页面**注入 `lab-bridge-parent.js`（持票据、代发上报）。**你的 HTML 不要写任何桥接 `<script src>`**（写了会被注入逻辑跳过，不会重复加载）。票据与真正的上报请求都在父页面，iframe 内只有这个无票据 shim。

| 方法 / 属性 | 说明 |
| --- | --- |
| `LabBridge.preview` | 预览模式为 `true`：跳过 `validate()` 与提交拦截，便于教师备课 |
| `LabBridge.validate()` | 经 `postMessage` 向父页面取回 `context`；必须在取配置前调用 |
| `LabBridge.context` | `{labId, submissionId, totalScore, gradeEndpoint}`（**不含票据**） |
| `LabBridge.reportGrade({total_score, elapsed_seconds})` | 经 `postMessage` 把分数交给父页面，由**父页面附加票据并代发 POST**；返回平台统一响应；**一次作答只允许成功上报一次**，成功后再调用会失效，失败会自动解除闸门以便重试 |

`context.totalScore` 是实验满分，页面判分时应以它为上限。平台**不提供步骤清单，也不下发票据**；页面按自己的逻辑组织步骤与分数，只负责把总分交给 `reportGrade()`。

> **四个 API 与 v3.1 完全一致**，AI 生成的页面无需改调用方式。变化的只是底层：iframe 是 opaque origin，读不到平台存储、发不了带自定义头的同源请求，所以 `validate()` / `reportGrade()` 走 `postMessage`。**不要自己写 `postMessage`**，一律用 `LabBridge`。

## 六、最简可运行示例（单 HTML）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>我的自定义实验</title>
  <style>
    body { font-family: system-ui, sans-serif; padding: 24px; }
    .task { padding: 12px; margin: 8px 0; border: 1px solid #ddd; border-radius: 8px; }
    button { padding: 8px 20px; font-size: 14px; }
    pre { background: #f6f8fa; padding: 12px; }
  </style>
</head>
<body>
  <h1>实验操作区</h1>
  <div id="tasks"></div>
  <button id="finish">完成并提交</button>
  <pre id="log"></pre>

  <script>
  (async function () {
    const log = (m) => { document.getElementById('log').textContent += m + '\n' }
    const startedAt = Date.now()

    // 预览模式（教师备课）不提交
    if (window.LabBridge && LabBridge.preview) { log('预览模式：不提交成绩'); return }

    // 1. 拿实验满分（票据只在平台父页面，iframe 内完全没有）
    const ctx = await LabBridge.validate()
    const maxScore = ctx.totalScore || 100

    // 2. 步骤与判分完全由页面自己决定；这里用三个任务示意
    const tasks = [
      { title: '任务一：配置 VLAN', score: 40 },
      { title: '任务二：配置路由', score: 40 },
      { title: '任务三：连通性验证', score: 20 }
    ]
    const box = document.getElementById('tasks')
    tasks.forEach((t, i) => {
      const div = document.createElement('div')
      div.className = 'task'
      div.innerHTML = `<label><input type="checkbox" data-i="${i}"> ${t.title}（${t.score} 分）</label>`
      box.appendChild(div)
    })

    // 3. 完成即出分：只算一个总分，上限用 ctx.totalScore
    document.getElementById('finish').onclick = async () => {
      let total = 0
      tasks.forEach((t, i) => {
        if (box.querySelector(`input[data-i="${i}"]`).checked) total += t.score
      })
      total = Math.min(Math.round(total * 10) / 10, maxScore)

      // 4. 上报两个值；平台补提交时间、按服务端时间重算用时并入库，实验即完成
      //    （页面这个 elapsed_seconds 如实填即可，只作留痕，不覆盖平台算出的用时）
      const res = await LabBridge.reportGrade({
        total_score: total,
        elapsed_seconds: Math.round((Date.now() - startedAt) / 1000)
      })
      log(JSON.stringify(res, null, 2))
    }
  })()
  </script>
</body>
</html>
```

> 真实实验把勾选框换成你的交互与判分逻辑即可。要点只有三个：**只算一个总分**、**以 `ctx.totalScore` 为上限**、**只调一次 `reportGrade`**。

## 七、上传 HTML 的硬性要求

本期只接收**单个 `.html` 文件**（≤50MB），所有 JS / CSS / 图片必须内联：

| 要求 | 原因 |
| --- | --- |
| 单文件，内联 `<style>` / `<script>`，图片用 data URI | 平台注入的 `<base>` 指向签名资产路由，**你自己的**相对路径资源取不到（`LabPage` 文件不在 `LABS_ROOT`）；平台桥接脚本例外，由签名资产路由提供 |
| 不引用外部 CDN | 门控页 CSP `script-src 'self' 'unsafe-inline'` 会拦外链脚本 |
| 不要自己写 `<base>` | 平台注入前会剥离已有 `<base>` |
| **不要写任何桥接 `<script src>`**（尤其 `lab-bridge.js`，那是 7 个预置实验用的） | iframe 内由平台注入 `lab-bridge-shim.js`，父页面注入 `lab-bridge-parent.js`；平台自动检测，已存在则跳过 |
| **不要试图读取票据或平台凭据** | 票据只在平台父页面，iframe 内（含 `window.LabBridge`）完全没有；不要读 `location.search`、不要自行拼 `X-Lab-Token`、不要自己发 `postMessage` |
| **不要读取 `localStorage` / `document.cookie` 里的平台登录信息** | v3.2 下你的页面在 **opaque origin 的沙箱 iframe** 内，这些存储**根本不可读**（访问抛 `SecurityError`），不是「靠自觉不读」；你的页面只应使用 `LabBridge`。平台门控页有严格 CSP、留存 sha256 与上传者；**上传时会做静态扫描**，命中 `localStorage` / `sessionStorage` / `document.cookie` / `window.opener` / `eval` / 外链 `src` / `sendBeacon` / `WebSocket` 等写法会被标记、要求二次确认并通知管理员；教师端可随时查看已上传源码。AI 生成页面时请把这一条也写进指令，避免生成埋点/统计代码 |
| 预览模式不提交 | `LabBridge.preview === true` 时跳过 `validate()` / 拦截 |

**不需要**：步骤清单配置、CORS 配置、https 证书、公网 IP/域名、独立源/DNS、API Key、任何后端服务。成绩上报由平台父页面代发，你的页面只调 `LabBridge`。

### 沙箱运行限制（v3.2，务必写进 AI 指令）

你的 HTML 运行在 `sandbox="allow-scripts allow-forms allow-modals"` 的 iframe 里，**没有** `allow-same-origin`，属于独立的 opaque origin：

| 限制 | 说明 |
| --- | --- |
| 读不到 `localStorage` / `sessionStorage` / `document.cookie` | 访问会抛 `SecurityError`；页面状态一律用 JS 变量保存，不要写浏览器存储 |
| 不能 `fetch` / `XMLHttpRequest` 平台 `/api/...` | opaque origin 下属跨域请求，平台未开放 CORS；**所有平台交互只能走 `LabBridge`** |
| 碰不到父页面 DOM / 变量 | 不要写 `window.parent.document` / `window.top`；跨域会被拦 |
| 不能导航顶层、默认不能开弹窗 | 未给 `allow-top-navigation` / `allow-popups`；`window.opener` 不可用 |
| **允许** | 内联 `<script>` / `<style>`、表单、`alert` / `confirm` / `prompt`、签名资产路由上的 `<script src>` / `<link>` / `<img>`（经典标签跨源加载不受 CORS 限制）、data URI 图片 |
| **禁止** | 外部 CDN、`eval` 动态加载、读浏览器存储、自行拼 `X-Lab-Token`、自己发 `postMessage` |

> 这些限制**正是为了让你的页面拿不到平台账号数据**。如果 AI 生成的代码里出现 `localStorage.setItem(...)` 或 `fetch('/api/...')`，上传时会被静态扫描标记（要求二次确认并通知管理员），运行时也一定会失败。

> 平台同时给 iframe 响应加严格 CSP（含 `form-action 'none'` / `base-uri 'self'` / `object-src 'none'`）、留存文件 sha256 与上传者，教师可随时查看已上传源码。**请按「会被审计的代码」对待上传文件**，不要粘贴来源不明的 AI 生成片段。

## 八、在线调试怎么用

教师端「成绩接口」Tab 提供 dry-run 调试，不产生真实提交：

1. 填一条模拟报文（就 `total_score` 与 `elapsed_seconds` 两个值，可点「生成满分 / 零分示例」）；
2. 点「发送调试请求」→ 平台用**与正式提交完全相同的校验链**跑一遍，不入库、不消费票据；
3. 结果区逐项显示：票据模拟、总分范围、用时合法性、报文大小；
4. 展示「若正式提交会写入的总分、用时与服务端提交时间」预览；
5. 摘要回写 `last_debug`，列表页显示「未验证 / 最近通过 / 最近失败」徽标。

常见失败原因：总分超过实验总分、小数位过多、用时为负。

## 九、身份鉴别、防刷分与诚实的上限

平台侧做的防护（极简档 **+ v3.1 加固 + v3.2 L2 沙箱**）：

| 层 | 措施 |
| --- | --- |
| 身份 | 一次性票据 `X-Lab-Token`，与本次作答一对一，2h 过期，提交成功即消费；服务端从票据反查实验与学生，页面无法指定别人的实验 |
| 身份 | **票据不进教师 HTML 文件 / iframe / `LabBridge` 公开 API / 接入说明**：只由平台父页面 `lab-bridge-parent.js` 的 IIFE 闭包持有，父页面代发上报时自动附带 |
| 隔离 | **教师 HTML 运行在 `sandbox` iframe（opaque origin，无 `allow-same-origin`）**：读不到浏览器令牌存储与 cookie、调不了平台 API、`window.opener` 受限；分数只经 `postMessage` 由父页面代发 |
| 页面 | 严格 CSP（`form-action 'none'` / `base-uri 'self'` / `object-src 'none'`）+ 上传静态扫描 + 源码二次确认 + sha256/上传者留痕 |
| 学籍 / 窗口 | 提交类学籍门控 + **实验发布状态与排课窗口在上报时二次校验**（截止后持有有效票据也拒绝） |
| 状态 / 并发 | 仅 `in_progress` 可提交，提交即锁定，默认不允许重做；**事务内对作答与票据加行锁、锁后复验、事务内消费票据**，挡并发双写与重放 |
| 频率 | 独立 `lab_grade` 限流 + 全站用户限流；`reportGrade()` 一次作答只允许成功一次，失败自动解除闸门以便重试 |
| 范围 | 总分 0~实验总分、1 位小数、报文 ≤64KB |
| 时间 | 提交时间与**正式用时**都由服务端生成 / 计算，不采信客户端时间 |
| 留痕 | 上报请求体原文 + 服务端上下文 + sha256，**教师可复核改分**；满分 + 极短用时自动标记 `abnormal`（只标记、不拒答） |

**必须知道的边界**：步骤与判分规则都在前端 HTML 里，平台不做结构或一致性校验。学生只要正常进入一次实验，就能在 DevTools 里直接调桥接方法或复制请求报一个满分；改写页面 JS 更不在话下。上述措施能挡住「无学籍/无票据直接 POST」「重复提交与重放」「并发双写」「越界分数」「伪造提交时间与用时」「截止后提交」，**并让教师 HTML 完全拿不到票据、读不到平台账号数据**；学生在**自己会话的平台父页面**用 DevTools 仍可报满分——**伪造满分挡不住**，这一项用户已明确接受。

**v3.2 明确列出的残余风险（三项生效，第四项不处理）**（完整威胁对照见规划文档 §八·补）：

1. **伪造满分不可根治** —— 判分在学生浏览器，除非改成服务端复算。用户已接受。
2. **票据在平台父页面运行期可见** —— 学生在自己会话中可从父页面的查看源码 / 网络面板看到**自己本次**票据；**iframe 内完全读不到**（opaque origin）。用户已接受。
3. **链接可转发看答案** —— 票据绑定某次作答，转发不会刷到别人的分，但会泄露答案、允许代做。用户已接受。
4. ~~页面内钓鱼~~ —— **本期不处理**。教师 HTML 已被 `sandbox` iframe 隔离，A 风险（平台数据层）闭环；仿冒 UI 属于教师上传内容的责任范围，用户 2026-11-05 16:00 明确「不用管」，**不设计治理、不列为残余风险、不写入告知义务**。严格 CSP 与上传静态扫描保留，用途是挡无心污染与外发通道。

**已评估但本期不做的加码方案**（避免以后重复讨论）：

| 方案 | 为什么不采用 |
| --- | --- |
| JS 加密 / HMAC 签名 / 代码混淆 | 密钥必须下发到浏览器，学生从源码即可取得；`CryptoKey.extractable=false` 只防导出密钥、不防调用 `sign()` 签任意内容；只挡顺手作弊，还给虚假安全感 |
| 服务端复算（AI 内嵌判分规则、教师零填报） | 唯一能真正防死的方案，但要页面改报原始作答、后端加规则解析与复算，规则表达力受限于结构化实验；与本期极简取舍不符 |

> **v3.2 更正**：「系统父页面 + `sandbox` iframe」已由用户拍板**采纳为正式架构**（本文 §一 / §五 / §七 与规划文档 §5.5），不再属于「不采用」方案；当初否决它只因「防刷分没用」，换成「隔离不可信 HTML」这个目标后它就是正确解。

若实验计入高利害成绩，建议：**启用教师复核改分、对满分提交人工抽查**；真要根治伪造满分再启用服务端复算（需改变「步骤都在 HTML」这一前提）。**平台数据层已由 L2 沙箱根治，不需要「优先安排独立源」**；L3 独立源只是后续可选项（多租户 / 非可信教师上传）。各档成本与影响面见规划文档 §八·补。

## 十、可直接复制给 AI 编程 agent 的指令

整段复制粘进你常用的 AI 编程工具，把实验的交互需求告诉它，让它生成/改造 HTML：

```text
请为我生成一个「单文件 HTML 交互实验页面」，用于上传到智课系统 V2 的自定义实验模块。
硬性要求（必须全部满足，否则平台会拒绝成绩上报）：

1. 单个 .html 文件，所有 CSS/JS 内联，图片用 data URI；不引用任何外部 CDN，
   不写 <base> 标签，不写任何桥接 <script src>（尤其 lab-bridge.js，那是平台预置实验用的）；
   平台会在沙箱 iframe 内注入 lab-bridge-shim.js、在父页面注入 lab-bridge-parent.js。
2. 平台会在沙箱 iframe 内提供 window.LabBridge（由平台注入的 lab-bridge-shim.js 提供，
   票据与真正的上报请求都在平台父页面，iframe 内没有票据）。
   页面启动后先调用 await LabBridge.validate()，
   从 LabBridge.context 读取 totalScore（实验满分）。
   票据只由平台父页面 lab-bridge-parent.js 的 IIFE 闭包私有持有、代发上报时自动附带，
   window.LabBridge 上没有任何票据属性，页面不需要也不应该接触票据：
   不要读取 location.search、不要存储票据、不要自行拼接 X-Lab-Token。
   若 LabBridge.preview 为 true，只做预览展示，不提交任何成绩。
3. 实验的步骤、每步名称、判分规则全部写在页面内，平台不提供也不接收步骤清单。
   请按下面我描述的实验需求组织交互并逐步判分，最终只算出一个总分。
4. 总分必须在 0 到 context.totalScore 之间，最多保留 1 位小数。
5. 学生点「完成并提交」时，只调用一次：
   await LabBridge.reportGrade({
     total_score: <页面算出的总分>,
     elapsed_seconds: <页面如实统计的实验耗时秒数>
   })
   平台只接收这两个值；提交时间由平台服务端生成，正式用时也由服务端按
   submitted_at - started_at 计算，页面不要传提交时间，也不要为了好看改写用时。
   上报成功后实验即完成，页面显示总分即可；失败时把平台返回的 message 显示出来，
   允许学生重试（失败不会作废票据，也不会锁死 reportGrade 闸门）。
6. 不要上报步骤明细、步骤 key、每步得分等任何额外字段；平台不需要。
7. 页面运行在 sandbox iframe（opaque origin）内：不要读取 localStorage /
   sessionStorage / document.cookie（会抛 SecurityError），不要 fetch 平台 /api，
   不要访问 window.parent / window.opener，不要自己发 postMessage；所有平台交互
   只用 window.LabBridge，页面内状态一律用 JS 变量保存。
8. 不引用外部 CDN、不粘贴来源不明的外部代码片段；平台会对上传文件做静态扫描
   （命中浏览器存储访问、外链、eval 等会标记并要求二次确认），留存文件 sha256
   与上传者，教师可随时查看已上传源码。

本实验名称与满分：
[粘贴系统「成绩接口」Tab 里显示的名称与总分]

本实验的交互与判分需求：
[在这里描述你的实验：学生要做什么、每步怎样算对、各步如何给分、总分怎么算]

请直接输出完整可保存为 .html 的代码，不要省略任何部分。
```
