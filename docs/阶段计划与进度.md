## 3. 各阶段详情

### P0 数据地基 ✅
- **做了什么**：`ClassStudent` 成为「学生在哪个班」的唯一事实源（`active/inactive` 占用），`User` 不挂 classroom 字段；单班由条件唯一约束 `uniq_occupied_class_per_student` 强制；入班/转班/移出统一走 `apps/classroom/services.py`；补学籍字段与 `Term` 学期字典。
- **关键决策**：不用 `User.classroom`（多源必打架）；转班置 `transferred` 而非 `removed`，保留历史。
- **验证**：L2 接口校验 + L3 浏览器校验 + 迁移前后计数存档，报告 `P0-测试报告.md`。

### P1 权限归口 ✅
- **做了什么**：班级 CRUD 全量归管理端；权限锚点从 `ClassRoom.teacher` 迁到 `Course.teacher`（前者降级为「建班人」留痕，读 `creator`/`creator_name`）；邀请码入班下线（`classes/join` 返回 410）；教师 PATCH 班级只能改 `courses` 且走**追加**语义。
- **关键决策**：`IsTeacher` 不含管理员（管理端看教师视图要 `IsTeacherOrAdmin`）——这条是 4 角色矩阵实测才暴露的。
- **验证**：`scripts/p1_permission_matrix.py` 4 角色 × 8 动作 64 断言；`test/e2e/p1-class-ownership-verify.js` 29 项；抓出 6 处真缺陷。
- **偏差**：教师选班前端抽屉推到 P3（已完成）；6 个历史班 `code` 为空（**今日已补齐**，见 §4）。

### P2 三类批量导入 ✅
- **做了什么**：`apps/platform_admin/imports.py` 统一管道（`ImportSpec → build_template → parse_excel → annotate_rows → commit` 单事务），三态 `ok/error/skipped`；学生导入按班级编码自动建班（预览页列待建清单、必须勾选）；前端 `components/admin/ImportWizard.vue` 三处复用。
- **关键决策**：`skipped`（已存在）不算失败、不触发回滚，保证重复上传幂等；`failed`（数据错）才整体回滚。
- **验证**：单测 30 项、`p2_import_api_check.py` 30 断言、E2E 57 项；抓出 4 处真缺陷（密码表班级列空、导入后看不到新班、名单页班名丢失、单班超 100 人截断）。
- **偏差**：导入不建 `Course` 关联（已由 P3 教师选班抽屉覆盖）。

### P3 课程复用 + 教师选班 ✅
- **做了什么**：`apps/courses/reuse.py` 资产整份复制 + `AITask.COURSE_REUSE` 异步任务；`GET/POST /api/courses/<id>/reuse-preview|reuse/`；前端 `CourseReuseDialog.vue`（资产清单 → 改名/选学期/勾选题库 → 阶段进度 → 结果摘要）；教师端班级行「课程」抽屉（P1 偏差收口）。
- **关键决策**：
  - **真复制，不共享路径**——删源课程不能连带毁掉副本（规范硬要求，也是共享路径方案必踩的坑）；
  - **向量不重算**——`KnowledgeChunk.embedding` 随行复制，复用后立即可检索，且不再产生一次 embedding 费用；
  - **产物一律 `status=inactive`**——教师核对后才启用，学生端才可见；
  - **班级绑定不复制**——`Material.classroom` 置空（班级专属资料不跟课走）。
- **验证**：L1 全量 **629 项 OK**；`scripts/p3_reuse_check.py` **30/30**（源课程 62 页 / 146 片段 / 139.6 MB：删源后副本 128 个文件完好、抽样页图配音 200、磁盘增量 0.00%）；E2E `p3-course-reuse-verify.js` 25/25、`p3-class-bind-verify.js` 12/12。62 页整份复制实测 **1.0 秒**。
- **修掉的缺陷**：挂课后接口回旧清单（prefetch 缓存未清）、教师选班误用 PUT 触发 400、`include_questions` 用 `bool()` 把 `"false"` 判成 True。

### B. 安全 / 架构债（建议 P5 或生产扩容前处理）
| 项 | 现状 | 风险 |
| --- | --- | --- |
| 无 TLS | 生产 `124.70.107.64:8088` 明文 HTTP |  token 与教学内容裸奔 |
| JWT 无登出吊销 | access 过期前无法作废 | 账号停用后旧 token 仍可用 |
| 交卷无真行锁 | 并发交卷靠应用层 | 极端并发下成绩可能错乱 |
| AI 无费用限流 | 按能力配了 provider，没配额 | 单用户可刷爆额度 |
| Mock 静默回退 | provider 不可用退回 mock | 演示时「假数据」被当真 |
| 外键 CASCADE | 删教师/学生会级联删班级、课程、成绩 | 误删不可恢复（方案 X-04 / X-25 / X-26 已定义处置：停用而非物理删） |
| `/api/docs/` 生产开放 | Spectacular 文档未关 | 接口结构暴露 |
| `catalogs/generate-from-plan/` 无 `IsTeacher` | 权限缺口 | 越权生成目录 |
| 全站无 throttle | 仅导入/导出有限流 | 暴力扫描与刷接口 |

## 7. 分支与提交流程（硬性）

1. **先规范后动手**：每阶段的任务写进 `docs/任务执行规范-组织重构与智课复用.md`（含「必须做 / 准出」）再开工。
2. **真实测试才算完成**：L1 单测 → L2 接口脚本 → L3 浏览器 E2E，三层齐了才准推送；E2E 数据自己建自己清。
3. **一个阶段可拆多个 commit**，但每个 commit 必须自洽可运行；migration 与模型改动同一个 commit。
4. **推送 = 阶段完成的唯一出口**：准出全过 → `docs/test-reports/P{N}-测试报告.md` + 规范补「完成记录」→ `git tag p{N}-done` → push 分支与 tag。
5. 禁止提交：`.env`、`db.sqlite3`、`media/`、`__pycache__`、临时测试脚本、截图（已由 `.gitignore` 覆盖）。
