信道划分

每个站点分配固定的信道资源（时隙、频段、码字），完全无冲突。

包括：时分复用(TDM)、频分复用(FDM)、码分复用(CDMA)

优点：无冲突，公平保证
缺点：资源固定分配，空闲站点浪费信道，灵活性差
🎲

随机接入

站点有数据就直接发送，允许冲突，冲突后通过超时重传恢复。

类似"想说就说"，冲突了再说

优点：简单，信道利用率高（负载轻时）
缺点：冲突频繁时性能急剧下降，重传可能再次冲突
👂

CSMA（先听后说）

发送前先监听信道，空闲才发送，尽量避免冲突。

类似"文明有礼的圆桌会议"

优点：大幅减少冲突概率
缺点：仍无法完全避免冲突（传播时延）

争用期（碰撞窗口）= 2τ

争用期是CSMA/CD协议中最核心的概念 — 它决定了站点发送数据后需要等待多久才能确认没有碰撞

信号传播与碰撞检测时间线

τ (单程传播时延)
τ (信号返回)
t=0 A开始发送
t=τ-t₁ B开始发送
t=τ 信号到达B
t=2τ-t₁ A检测到碰撞

关键结论：
站点A在t=0开始发送，站点B在t=t₁开始发送（t₁ ≤ τ）。
B检测到碰撞的时间：t = τ - t₁（B发送后很快就能检测到）
A检测到碰撞的时间：t = 2τ - t₁（信号需要从B传回A）

最坏情况：A需要等待 2τ 才能确认没有碰撞
这就是为什么争用期 = 2τ — 信号往返时间

为什么载波监听不能完全避免碰撞？

当站点A和站点B同时发现信道空闲时，它们都会开始发送数据。 由于电磁波传播需要时间（即使光速也有时延）， A的信号到达B需要τ时间，在这段时间内B无法感知A已经在发送。

最短帧长 = 2τ × 数据率

为了确保发送站点在发送过程中能检测到碰撞，帧的发送时间必须大于争用期2τ。
否则，站点可能在碰撞信号传回之前就已经发送完毕，无法检测到碰撞。

最短帧长 = 2τ × 数据率

对于10Mb/s以太网：
争用期 = 51.2μs（2τ）
最短帧长 = 51.2μs × 10Mb/s = 512比特 = 64字节
这就是以太网最短帧长64字节的由来

二进制指数退避算法

碰撞后不是立即重传，而是等待一段随机时间 — 这就是退避算法

算法规则

1. 基本退避时间 = 1个争用期（2τ）
2. 定义重传次数 k = Min(实际重传次数, 10)
3. 从整数集合 [0, 1, 2, ..., 2^k - 1] 中随机选择一个数 r
4. 等待时间 = r × 2τ
5. 当重传次数达到16次时，丢弃该帧并向高层报错

核心思想：卷入冲突的站点越多，随机选择退避时间的范围就越大， 从而让各站点在不同的时间重传，减少再次冲突的概率。

确保发送站点在发送过程中能检测到碰撞

二进制指数退避

碰撞后等待随机时间重传

等待时间 = r × 2τ

r：从[0, 2^k - 1]中随机选择
k = Min(重传次数, 10)
最大重传次数：16

碰撞检测条件

两个站点在争用期内同时发送数据

发送时间 ≤ 2τ → 可检测碰撞

如果帧发送时间 > 2τ
则发送过程中一定能检测到碰撞
这也是最短帧长存在的原因

冲突检测时间计算

A在t=0发送，B在t=t₁发送（t₁ ≤ τ）

A检测到碰撞：t = 2τ - t₁

B检测到碰撞：t = τ - t₁
最坏情况：A等待2τ才能确认无碰撞
这就是争用期=2τ的数学证明

帧间间隔

IFG = 9.6μs (10Mb/s)

所有站点在发送数据后
必须等待9.6μs才能发送下一帧
让总线恢复到空闲状态

思考题与作业

思考题1：网络规模增大时的问题

当网络覆盖范围增大，连接站点数增多时，CSMA/CD会有什么问题？

1. 传播时延τ增大 → 争用期2τ增大 → 最短帧长需增大 → 网络效率下降
2. 站点增多 → 碰撞概率增大 → 退避次数增多 → 平均等待时间增大
3. 极端情况下，信道可能被大量碰撞和退避占据，有效吞吐率趋近于零
4. 这正是CSMA/CD在大型网络中被交换式以太网取代的原因

思考题2：随机接入 vs 静态信道划分

请分析比较随机接入和静态信道划分各自的优缺点。

静态信道划分（TDM/FDM/CDMA）：
优点：无冲突，公平保证，适合恒定速率业务
缺点：资源固定分配，空闲站点浪费信道，不适合突发性数据

随机接入（CSMA/CD）：
优点：信道利用率高（负载轻时），灵活，无需预先协调
缺点：负载重时碰撞频繁，性能急剧下降，无法保证公平性和延迟上限

结论：轻负载时随机接入更优，重负载时信道划分更稳定

思考题3：为什么基本退避时间是1个争用期？

为什么基本退避时间取1个争用期（2τ），而不是更短或更长？

1. 2τ是检测碰撞所需的最长时间 — 等待2τ后信道一定恢复空闲
2. 如果退避时间 < 2τ，可能碰撞信号还未传播完毕，重传会再次碰撞
3. 如果退避时间 > 2τ，则浪费信道时间，降低效率
4. 因此2τ是最合理的基准退避时间单位

思考题4：为什么k的上限是10？

二进制指数退避算法中，为什么k = Min(重传次数, 10)，而不是让k无限增长？

1. k=10时，随机数范围已达[0, 1023]，退避时间最大可达1023×2τ
2. 如果k继续增大，退避时间范围过大，平均等待时间过长
3. 限制k的上限可以避免个别站点等待过久，保证一定的公平性
4. 当重传16次仍失败时，说明网络拥塞严重，应丢弃帧并报错
